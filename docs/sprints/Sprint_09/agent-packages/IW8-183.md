## 10. Story-specific algorithm / pseudocode

1. Validate/normalize structured filters into internal SearchCriteria.
2. Apply mandatory visibility/state/privacy predicates before optional filters.
3. Apply indexed scalar and bridge-table predicates; never parse critical data from description text.
4. Apply deterministic sort with unique Id tie-breaker.
5. Fetch first+1 rows to compute pageInfo and encode opaque cursor from sort tuple.
6. If facets are requested, compute counts against the same base filter context while excluding only the facet dimension being counted as designed.
7. Return DTO/read-model rows only; hydrate canonical detail separately when required.
